# Testing-podo
Dépôt d'essai pour apprendre à utiliser Git et GitHub.

## Étapes de base

1. Créer une branche : `git checkout -b ma-branche`
2. Modifier des fichiers
3. Enregistrer les changements : `git add .` puis `git commit -m "message"`
4. Envoyer sur GitHub : `git push -u origin ma-branche`
5. Ouvrir une Pull Request sur GitHub pour fusionner dans `main`
